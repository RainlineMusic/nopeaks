# NOPEAKS: первая проверка в Ableton Live

Это исследовательская версия 0.1.0. Она реализует реальное управление дорожками, но ещё требует прослушивания на настоящих проектах и проверки поведения конкретной DAW.

## Установка

Скачайте ZIP для Windows из успешной сборки [Actions](https://github.com/RainlineMusic/nopeaks/actions). Распакуйте оба каталога `.vst3` в `C:\Program Files\Common Files\VST3\Rainline Music\` и выполните повторное сканирование VST3 в Live. Для macOS стандартный каталог `/Library/Audio/Plug-Ins/VST3/`; сборка пока без подписи и нотарификации.

## Подключение

1. Выберите один уровень: группы или отдельные дорожки. Установите `NOPEAKS Track` последним на каждом источнике, который входит в мастер. Возвраты тоже считаются источниками. Не ставьте Track одновременно на группу и входящие в неё дорожки.
2. В первой версии после Track до Master должен быть прямой суммирующий тракт с единичным усилением: фейдеры после вставки 0 dB, без дополнительной обработки и панорамирования. Необходимое усиление/панораму сделайте перед Track. Это ограничение текущей модели, а не требование VST3 вообще.
3. На мастер установите `NOPEAKS Master`. Поставьте одинаковые `Project ID` и `Link group`. В другом одновременно открытом проекте используйте другой Project ID.
4. В Track введите понятное имя. У вокала и основных ударных поднимите Priority; источники, которые запрещено менять, отметьте Protect track.
5. Запустите воспроизведение. Master должен увидеть источники и подтвердить суммирование. Затем включите `Track control`. Если проверка не проходит, адресная обработка не включится. Проверьте фейдеры, эффекты после вставок, возвраты, отсутствие двойного учёта и поведение компенсации задержки.

## Параметры

| Параметр | Действие |
| --- | --- |
| Peaks | Распределяет ослабление пиков между Track с учётом их приоритета |
| Ceiling | Порог предсказанной суммы и выходной защиты Master |
| Safety | Дополнительное ограничение sample peak на Master |
| Tone | Доля коррекции относительно Capture balance |
| Capture balance | Сохраняет нормированное распределение энергии за 2 секунды активного сигнала Track |
| Conflicts | Ограниченная эвристика частотных пересечений; приоритетные источники меняются меньше |
| Width | Подавляет Side в проблемных полосах с отрицательной корреляцией на Master |
| Protect track | Исключает источник из прямых коррекций Track; Safety на мастере действует на всю сумму |
| Bypass | Обход с сохранением объявленной задержки |

Для проверки тембрального баланса сначала выставьте Conflicts=0. Нажмите Capture balance на удачном фрагменте, дождитесь завершения измерения и перейдите к более перегруженному фрагменту. Плагин пытается убрать избыток, выбирая дорожки меньшего приоритета. Он не строит универсальную правильную кривую и не добавляет отсутствующие частоты.

Для проверки пиков начните с двух Track, оставьте Tone/Width выключенными, установите Ceiling=-1 dB. Защитите один источник; убедитесь, что коррекция преимущественно достаётся второму. Safety оставьте включённой. Ограничитель защищает отсчётные пики, но не гарантирует true peak.

Задержка Track → Master составляет 8448 отсчётов, около 176 мс при 48 kHz. Это режим сведения; для записи с мониторингом он неудобен. Внешние эффекты между Track и Master, смешение обработанных/необработанных веток и особенности PDC могут сделать координацию недоступной. При этом Safety Master работает отдельно.

Отрицательную корреляцию нельзя всегда исправить одним уменьшением Side: при чистом противофазном сигнале Mid отсутствует. Контролируйте моносовместимость на слух и отдельным коррелятором.

Сообщения о проблемах полезно дополнять версией Live, размером буфера, частотой дискретизации, схемой маршрутизации и статусом Routing в Master.
